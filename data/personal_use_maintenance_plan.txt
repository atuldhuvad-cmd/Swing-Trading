================================================================================
1. NORMAL PERSONAL USE
================================================================================

Use the app as an evidence and execution journal — not an automated trading system.

A. Genuine NSE OHLCV updates
   - Source: verified NSE cash EQ CSV files under manual_inputs/nse/ (or equivalent).
   - Import via UI: Market Data path / import flows, or controlled scratch scripts that
     call OhlcvService.confirm_import (see scratch/batch_*_production_import.py).
   - Never insert synthetic or placeholder OHLCV into production.

B. Verified fundamental evidence updates
   - Source: manually verified annual/report PDFs or structured intake under
     manual_inputs/fundamentals/.
   - Import via UI: /fundamentals/import (preview → confirm).
   - Preserve provenance: entity type, source line item, period, KNOWN/UNKNOWN status.
   - Insurance entities (e.g. HDFCLIFE) use insurance line items, not ordinary revenue labels.

C. Controlled Phase 5 re-evaluation
   - Run only when OHLCV and/or fundamentals have materially changed for covered stocks.
   - Use scratch/batch_b_phase5_reeval.py (or successor controlled script) — it appends
     NEW candidate_evaluation_run rows; it does not rewrite historical evaluations.
   - Phase 5 config fingerprint must remain:
     146408d7d5de3ce55acd5465d2c788acca9d8e1875c21e1af470151a3f0f97fe
   - FINAL_CANDIDATE means “passes Phase 5 trend screen” — not BUY.

D. Deliberate manual broker-opinion evidence
   - Enter via Recommendation Entry (/recommendations/new) or Import Wizard (/imports/new).
   - Attach official source URL, dates, verification status (VERIFIED_PRIMARY preferred).
   - Provisional/rejected sources must not inflate the Broker Opinion Universe.
   - Consensus is display-only on evidence pages; it does NOT gate Phase 5.

E. Manual Trade Journal use
   - Browse Final Candidates → Evidence → Plan Trade → Journal (/trades).
   - Lifecycle: PLANNED → OPEN → CLOSED, or PLANNED → CANCELLED.
   - Entry/exit prices and price sources are typed manually at execution time.
   - No live prices, no OHLCV/planned/target substitution, no broker auto-fill.

================================================================================
2. SAFE UPDATE ORDER (history-first)
================================================================================

When refreshing market or fundamental evidence for existing NIFTY-50 coverage:

  1. BACKUP production DB (see §3).
  2. Confirm stock exists in Master Data (/master) — register new symbols first if needed.
  3. Import genuine OHLCV for affected symbols.
  4. Verify Market Data Status (/market-data): session counts, SMA200 readiness, latest date.
  5. Import verified fundamentals for affected symbols (preview must match confirm payload).
  6. Run controlled Phase 5 re-evaluation (creates new eval + criterion + RR rows).
  7. Review Candidate Evaluation (/final-candidates) and Evidence detail (/evidence/:id).
  8. Optionally add/update broker recommendations (separate from Phase 5 classification).
  9. Optionally plan/open/close trades in Trade Journal (personal execution only).

Immutable / history-first rules:
  - Do not delete or overwrite prior candidate_evaluation_run, criterion, or RR history.
  - Do not mutate OHLCV/fundamentals to “fix” a classification — add corrected evidence instead.
  - Do not run workflow validation or e2e trade tests against production (use DB copy).
  - Trade Journal rows are preserved through CANCELLED/CLOSED terminal states.
